# My personal blog

https://sfi0zy.github.io

## Description

This blog is a part of a larger project aimed at resolving the theory crisis in psychology and psychiatry by replacing the current paradigm with a new species-agnostic approach rooted in physics and logic.

It features:

- Online version of the [evolutionary theory of behavior](https://sfi0zy.github.io/evolutionary-theory-of-behavior/).
- Additional [essays on various related topics](https://sfi0zy.github.io/tag/evolution/).

In the form of a casual conversation, we question the validity of some well-established terms and methods, replace emotional poetry with cold-blooded engineering, build a mechanical model of the psyche, and rediscover all major psychiatric diseases as predictable malfunctions in an information processing machine.

## Development

```sh
git clone git@github.com:sfi0zy/sfi0zy.github.io.git
cd sfi0zy.github.io
npm i
npm run lint
npm run build
npm run serve
```
